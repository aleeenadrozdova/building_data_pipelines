# HW6

Задание: Реализуйте 3 кейса, где DataFrame гарантированно быстрее любого. Для каждого 
кейса приведите код и объясните, какая оптимизация Catalyst/Tungsten дает выигрыш.
Возможные кейсы:
• Множественные агрегации — df.groupBy().agg(sum, avg, min) vs несколько RDD-действий
• Оконные функции — топ-N в группе против сортировки + фильтрации на RDD
• Работа с вложенными типами — struct/array без сериализации vs парсинг на RDD
• Условная логика (when/otherwise) против множественных filter + union на RDD
(*) Найдите 2 кейса, где SQL-запрос выполняется быстрее эквивалентного DataFrame API. 
Сравните планы выполнения через explain() и объясните причину разницы.
Результат: Отчет с таблицами производительности и выводами, когда какой API выбирать.
