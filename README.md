# Building Data Pipelines — курс по построению пайплайнов данных

Сквозная тема: **Аналитическая платформа e-commerce (интернет-магазин/маркетплейс)**.

Рабочее имя платформы: **RetailFlow**.

## Домен

Интернет-магазин. Данные, с которыми работаем во всех ДЗ:

| Слой | Что это |
|---|---|
| Источники | События мобильного/веб-приложения (view, cart, purchase, navigation), логи веб-сервера, транзакционная БД (заказы/платежи/доставка/продавцы), внешние API (доставка, маркетинг) |
| Поток | События → Kafka → Spark (batch, стриминг) → озеро данных |
| Озеро | Raw (Iceberg/Delta) + обработанные слои (bronze/silver/gold) в Parquet/Avro |
| Витрины | Продажи по категориям, поведение пользователей, оценка офферов/продавцов |
| Аналитика | Trino/StarRocks по витринам |
| Оркестрация | Argo Workflows (batch-джобы Spark) |
| Инфра | Kubernetes, секреты, CI/CD (GitLab CI), мониторинг (Prometheus + Grafana) |

## Карта ДЗ в рамках темы

| ДЗ | Задание | Реализация в теме |
|---|---|---|
| hw1 | Архитектура пайплайна | Полная архитектура RetailFlow |
| hw2 | Объективная система оценки (data product) | Оценка преподавателей университета: 3 user story, Data Product Canvas, 2 метрики качества + SLA |
| hw3 | Бенчмарк 3+ форматов (~10 ГБ) | События покупок: Parquet, Avro, CSV (+JSON) — объём/запись/чтение |
| hw4 | Доказать преимущества RDD | Обработка «грязных» сырых событий с нерегулярной схемой, кастомная сессионизация, ручное управление партициями/памятью |
| hw5 | Оптимизация Spark | Проблемы (shuffle, перекосы, сетецкие партии) + оптимизации (coalesce, bucketing, broadcast, AQE, кэш) |
| hw6 | Доказать преимущества DataFrame | Агрегации, оконные топ-N, nested-типы на событиях + (*) 2 кейса где SQL быстрее DF API (explain) |
| hw7 | Табличные форматы (Hudi/Delta/Iceberg) | Версионирование витрин/источников событий: Delta/Iceberg; кейс оправданности каждого |
| hw8 | Kafka-пайплайн | Топики событий (view/cart/purchase/delivery), партиции/ключи, политики хранения, гарантии доставки, consumer-группы |
| hw9 | Сравнение SQL-движков | Trino vs StarRocks: бенчмарки, различия, риски, решение |
| hw10 | Секреты в K8s | native Secrets vs Vault vs external-secrets/SealedSecrets |
| hw11 | Универсальные WorkflowTemplate | 3+ темплейта (spark-job, notify, data-quality) + основной workflow |
| hw12 | CI/CD в K8s | Структура репозиториев + пайплайн сборки/деплоя Spark, Helm-продуктов, витрин |
| hw13 | Мониторинг | Prometheus + Grafana: 5+ метрик, 3+ дашборда, 4+ правила алертинга, сбор метрик короткоживущих Spark-джоб |
